# 公開までの手順書

デュエマ カード一覧（非公式）を、インターネットに公開するまでの手順です。
すべて無料で行えます。上から順番に進めてください。

所要時間の目安：作業は1時間ほど。そのあと、初回のカードデータ集めに数日かかります（自動で進みます）。

---

## 1. 専用の Gmail を作る

このサイトの問い合わせ先（削除依頼などの窓口）として使います。普段使っているメールアドレスとは別にしてください。

1. ブラウザで Google アカウントの作成ページを開き、新しいアカウントを作ります。
2. できたアドレス（例：`dm-viewer-xxxx@gmail.com`）を控えておきます。

## 2. GitHub のアカウントを作り、プログラムを置く

GitHub は、プログラムの保管と、毎日の自動更新に使います。

1. https://github.com でアカウントを作ります（1. の Gmail で登録すると管理しやすいです）。
2. 右上の「＋」→「New repository」を押します。
3. 「Repository name」に `dm-card-viewer` などの名前を入れ、**Public** を選んで「Create repository」を押します。
   - Public にすると、毎日の自動更新（GitHub Actions）を無料の範囲で使えます。
4. 作ったリポジトリの画面に出る「…or push an existing repository from the command line」の3行を、このフォルダで実行します。
   ```bash
   git remote add origin https://github.com/あなたのユーザー名/dm-card-viewer.git
   git branch -M main
   git push -u origin main
   ```
   ※ いまの作業ブランチ（`feat/dm-card-viewer`）を main にまとめてから push します。わからなければ Claude に「GitHub に push したい」と伝えてください。

## 3. Cloudflare Pages でサイトを公開する

1. https://dash.cloudflare.com でアカウントを作ります。
2. 左のメニューから「Workers & Pages」→「作成」→「Pages」タブ →「Git に接続」を選びます。
3. GitHub と連携し、2. で作ったリポジトリを選びます。
4. 「ビルドの設定」は次のとおりにします。
   - フレームワーク プリセット：**なし**
   - ビルド コマンド：**空のまま**
   - ビルド出力ディレクトリ：**`site`**
5. 「保存してデプロイ」を押します。数十秒で `https://（プロジェクト名）.pages.dev` という URL が発行されます。これがあなたのサイトの URL です。

この時点では、見本の50枚だけが表示されます。

## 4. サイトの URL と Gmail を書き込む

次の2つのファイルの `TODO_…` の部分を書き換えます。

- `scraper/config.js`
  ```js
  export const SITE_URL = 'https://（プロジェクト名）.pages.dev';
  export const CONTACT_EMAIL = '（1. で作った Gmail）';
  ```
  公式サイトを読み取るときに「誰が読み取っているか」として相手に伝わります。**書き換えるまで、読み取りプログラムは動きません。**
- `site/js/app.js`
  ```js
  const CONTACT_EMAIL = '（1. で作った Gmail）';
  ```
  サイトの下に「お問い合わせ・削除依頼」として表示されます。

書き換えたら GitHub に push します（Claude に頼んでも構いません）。Cloudflare が自動でサイトを更新します。

## 5. カードデータの自動更新を始める

1. GitHub のリポジトリ画面で「Actions」タブを開きます。
2. 「I understand my workflows, go ahead and enable them」が出たら押します。
3. 左の「update-cards」→「Run workflow」→「Run workflow」を押します。

初回は全カード（約2万4千枚）を、公式サイトに負担をかけないよう1秒に1枚ずつ読みます。1回の実行は最大5時間半で止まり、翌日の自動実行で続きから進むので、**全部そろうまで2日ほど**かかります。そろうまでは、サイトは見本の50枚のままです。

そのあとは毎日 日本時間 3:00 に自動で起動し、

- 新しいカードの確認：週1回
- 全カードの読み直し（能力の文章の修正なども反映）：月1回

を行います。変更があれば自動でサイトに反映されます。

## 6. 確認する

- サイトの右上の枚数が、公式のカード検索の枚数（「同名カードをまとめる」をオフにしたとき）とほぼ同じになっているか。
- カードを選ぶと、公式・メルカリ・カーナベル・YouTube のボタンが正しく開くか。
- スマホでも見やすいか。

## うまくいかないとき

- **GitHub から「Run failed」のメールが届いた**：公式サイトの作りが変わって、カードの情報を読み取れなくなった可能性があります。サイトは壊れたデータでは更新されず、前のデータのまま表示され続けます。Claude にメールの内容を見せて、直してもらってください。
- **サイトでカードの画像が出ない**：公式サイトが外部からの画像表示を止めた可能性があります。その場合も、文字のカードで一覧は使えます。
- **削除依頼が届いた**：権利者からの依頼であれば、すぐにサイトを非公開にしてください（Cloudflare の Pages の設定からプロジェクトを削除できます）。
